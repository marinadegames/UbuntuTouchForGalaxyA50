# Samsung Galaxy A50 Linux recovery state

Working device: Samsung Galaxy A50 SM-A505F (`a50`), Ubuntu Touch 26.04-1.x.

## Confirmed working on the phone

- Linux boots to Lomiri at 1080x2340 using the Android/libhybris graphics stack.
- USB serial console is available as `/dev/cu.usbmodemA50LINUX1`.
- Wi-Fi scans and connects through `swlan0`.
- OpenSSH is enabled; the local Ed25519 public key is authorized for `phablet`.
- Display brightness and display-off without suspend work through `repowerd`.
- PulseAudio uses `sink.primary-out` and the `output-speaker` port.
- Camera compatibility library `libexiv2.so.27` was added for Camera 4.1.1.

## Live fixes made after the patched installer

- Made `/usr/local/bin/a50-container-prepare.sh` executable.
- Disabled the incorrect `NetworkManager.service.d/a50-vendor.conf` dependency.
- Started/enabled NetworkManager, Android LXC preparation, LightDM/Lomiri, repowerd, and SSH.
- Made `/usr/local/bin/a50-audio-speaker-route.sh` and `/usr/local/bin/a50-audio-hidl-compat.sh` executable.
- Disabled `a50-screen-off.service`; repowerd is configured for display-off after 60 seconds without suspend.
- Added Ubuntu Noble ARM64 `libexiv2.so.27` compatibility library for the camera app.

## Gold-image backup still required

The exact running system is `/data/ubuntu.img` on the phone. To preserve every live fix, boot TWRP and copy that file while it is not mounted by Linux. Also capture the boot partition. Store checksums beside both files.

Do not overwrite the current phone installation until this gold-image backup has been verified.
